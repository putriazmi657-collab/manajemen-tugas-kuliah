# Manajemen Tugas Kuliah

Aplikasi sederhana untuk membantu mahasiswa mengelola tugas perkuliahan.

## Teknologi
- TypeScript
- Vite
- HTML
- CSS

## Fitur
- Menambahkan tugas kuliah
- Mengedit tugas
- Menghapus tugas
- Mengubah status tugas
- Mencari dan memfilter tugas
- Menyimpan data menggunakan localStorage

## Cara Menjalankan
1. Install dependencies dengan npm install.
2. Jalankan aplikasi dengan npm run dev.
3. Buka alamat localhost yang ditampilkan oleh Vite.
